Приложение использует меню Gum на Linux, Windows и macOS. В Windows его запускает PowerShell. Ниже показаны экраны русскоязычного меню.

## Главное меню

![Главное меню Telegram Vacancy Monitor](../../assets/standalone/01-main-ru.png)

В меню доступны запуск мониторинга, проверка готовности, определение Telegram ID, справка и переключение языка.
