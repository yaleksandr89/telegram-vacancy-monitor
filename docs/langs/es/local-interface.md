La aplicación utiliza menús Gum en Linux, Windows y macOS. En Windows la inicia PowerShell. Las siguientes capturas muestran el menú en ruso.

## Menú principal

![Menú principal de Telegram Vacancy Monitor](../../assets/standalone/01-main-ru.png)

El menú permite iniciar el seguimiento, comprobar la preparación, identificar el Telegram ID, abrir la ayuda y cambiar el idioma.
