## 报告漏洞

请使用 [GitHub Security Advisories](https://github.com/yaleksandr89/telegram-vacancy-monitor/security/advisories) 中的 **Report a vulnerability** 功能提交保密报告。如果无法使用私有表单，请在 [Issues](https://github.com/yaleksandr89/telegram-vacancy-monitor/issues) 中请求私密联系方式，但不要公开漏洞细节。

## 安全范围

安全问题包括：

- 令牌、API 密钥和私有配置泄露;
- 绕过允许发送者验证或 Webhook 安全保护;
- 未经授权访问职位、候选人档案、分析结果和 SQLite 数据;
- 不安全地处理不可信消息或 AI 模型响应;
- 发行版应用程序的完整性遭到破坏.

## 报告内容

请提供受影响的应用版本或 commit、潜在影响和复现步骤。提交前删除有效密钥、私人聊天内容和个人数据。

## 披露

请与项目维护者协调技术细节的发布时间，以便在公开漏洞前准备修复。
