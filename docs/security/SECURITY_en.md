## Reporting a vulnerability

Use [GitHub Security Advisories](https://github.com/yaleksandr89/telegram-vacancy-monitor/security/advisories) and the **Report a vulnerability** feature for confidential reports. If the private form is unavailable, open an [Issue](https://github.com/yaleksandr89/telegram-vacancy-monitor/issues) requesting a private contact channel without describing the vulnerability.

## Security scope

Security concerns include:

- exposure of tokens, API keys, and private configuration;
- bypassing allowed-sender verification or webhook protection;
- unauthorized access to vacancies, candidate profiles, analysis results, or SQLite data;
- unsafe handling of untrusted messages or AI model responses;
- compromising the integrity of distributed applications.

## Report contents

State the affected application version or commit, possible impact, and reproduction steps. Remove active secrets, private conversations, and personal data before submitting.

## Disclosure

Coordinate publication of technical details with the maintainer so a fix can be prepared before public disclosure.
