# Настройка Telegram-бота

Для работы нужен бот, созданный через BotFather. В `TELEGRAM_ALLOWED_USER_ID` указывается числовой ID аккаунта Телеграмма, от которого приложение принимает вакансии и которому отправляет результаты.

## Создайте бота

1. Откройте [BotFather](https://t.me/BotFather) в Телеграмме и отправьте `/newbot`.
2. Задайте отображаемое имя и имя пользователя бота по подсказкам.
3. Сохраните выданный токен в приватном `config/bot.ini`, созданном по [образцу](../../config/bot.example.ini).
4. Откройте созданного бота и отправьте `/start`.

Токен даёт доступ к боту. Храните его в INI, не вставляйте в команды, снимки экрана, обращения в Issues или публичные примеры. Если он раскрыт, перевыпустите его через BotFather, обновите конфигурацию и перезапустите обработку. Управление ботами описано в [официальном руководстве BotFather](https://core.telegram.org/bots/features#botfather).

## Узнайте свой ID

Для первого определения ID оставьте `TELEGRAM_RECEIVE_MODE = "polling"`. Токен уже должен быть заполнен; ID пользователя, профиль и параметры модели для поиска ещё не нужны.

**В локальном приложении:** запустите `./vacancy-monitor` в Linux/macOS или `.\vacancy-monitor.exe` в PowerShell. Выберите «Узнать Telegram User ID», затем «Проверить сейчас».

**В установке из исходников:** из корня проекта выполните:

```bash
php bin/bot.php identify
```

После проверки появится числовой ID аккаунта, с которого отправлен `/start`. Запишите **свой ID** в `TELEGRAM_ALLOWED_USER_ID` в `config/bot.ini`. Имя с `@` и ID бота сюда не подходят.

Если ID не появился, снова отправьте `/start` и повторите проверку. Если ботом пользовались несколько человек, в списке могут быть несколько ID: определите свой и запишите только его.

Поиск выполняет один запрос `getUpdates`, не подтверждает обновления и не записывает ID в БД. Он не должен работать одновременно с другим polling-процессом. При зарегистрированном webhook сначала выполните [переключение режимов](vds-webhook.md#переключение-режимов). Логика поиска находится в [`bin/bot.php`](../../bin/bot.php).

## Завершите настройку

Подготовьте [профиль и инструкции](../../config/profile/README.md), затем [подключите ИИ](ai-models.md). Запустите мониторинг локально либо настройте [webhook и cron](vds-webhook.md).

Для поиска ID достаточно отправить `/start` и выполнить проверку. После запуска мониторинга бот отвечает на `/start` приглашением переслать вакансию.

## Как отправлять вакансии

- Отправьте боту текст вакансии обычным сообщением.
- Или перешлите публикацию из чата или канала в чат с ботом.
- Если текст находится в подписи к вложению, приложение также сможет его обработать. Сами изображения и голосовые сообщения не распознаются.

После получения вакансии бот подтвердит её сохранение, а затем отправит оценку. [Как обрабатываются повторы и пересылки](message-processing.md) и [как читать результат](../reference/analysis-result.md). Если сообщение не приходит, посмотрите [устранение неполадок](troubleshooting.md).
