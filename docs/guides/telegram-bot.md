# Бот и разрешённый пользователь

Приложение работает через официальный Telegram Bot API с токеном вашего бота. Вакансии принимаются только в личном чате и только от пользователя, указанного в `TELEGRAM_ALLOWED_USER_ID`.

## Создайте бота

1. Откройте [BotFather](https://t.me/BotFather) в Телеграмме и отправьте `/newbot`.
2. Задайте отображаемое имя и имя пользователя бота по подсказкам.
3. Сохраните выданный токен в приватном `config/bot.ini`, созданном по [образцу](../../config/bot.example.ini).
4. Откройте чат с новым ботом по ссылке BotFather и отправьте `/start`.

Токен даёт доступ к боту. Храните его в INI, не вставляйте в команды, снимки экрана, обращения в Issues или публичные примеры. Если он раскрыт, перевыпустите его через BotFather, обновите конфигурацию и перезапустите обработку. Управление ботами описано в [официальном руководстве BotFather](https://core.telegram.org/bots/features#botfather).

## Узнайте свой ID

Для первого определения ID оставьте `TELEGRAM_RECEIVE_MODE = "polling"`. Токен уже должен быть заполнен; разрешённый ID, профиль и параметры модели для поиска ещё не нужны.

**В локальном приложении:** запустите `./vacancy-monitor` в Linux/macOS или `.\vacancy-monitor.exe` в PowerShell. Выберите «Узнать Telegram User ID», затем «Проверить сейчас».

**В установке из исходников:** из корня проекта выполните:

```bash
php bin/bot.php identify
```

Вы получите ID отправителей ожидающих сообщений, начинающихся с `/start`. Запишите свой положительный числовой ID в `TELEGRAM_ALLOWED_USER_ID`, сохранив кавычки INI. Имя пользователя с `@` и ID самого бота для этого не подходят.

Если результатов нет, отправьте `/start` нужному боту ещё раз и повторите проверку. При нескольких ID не разрешайте всех подряд: убедитесь, какой принадлежит вам. Для первичной настройки удобен бот, которому ещё не писали другие люди.

Поиск выполняет один запрос `getUpdates`, не подтверждает обновления и не записывает ID в БД. Он не должен работать одновременно с другим polling-процессом. При зарегистрированном webhook сначала выполните [переключение режимов](vds-webhook.md#переключение-режимов). Логика поиска находится в [`bin/bot.php`](../../bin/bot.php).

## Завершите настройку

Подготовьте [профиль и инструкции](../../config/profile/README.md), затем [подключите ИИ](ai-models.md). Запустите мониторинг локально либо настройте [webhook и cron](vds-webhook.md).

Пока приём сообщений не запущен, бот может не отвечать на `/start`: команда поиска ID только читает ожидающие обновления. Работающий бот отвечает предложением переслать вакансию.

## Как отправлять вакансии

- Перешлите публикацию с текстом из доступного вам чата или канала в личный чат с ботом.
- Или отправьте текст объявления обычным сообщением.
- У вложения может использоваться текстовая подпись. Изображения, документы и голосовые сообщения сами по себе не распознаются.
- Отправляйте полное описание. Сообщение с одной ссылкой не загрузит содержимое страницы: ИИ увидит только присланный текст.

После успешного сохранения приходит «Вакансия сохранена.». Для известной публикации возможен ответ «Эта публикация уже сохранена.». Повтор различается по идентификаторам входящих сообщений и подтверждённым данным исходной публикации; одинаковый текст из неизвестных источников сам по себе не объединяется. Правила приёма задаёт [`IncomingUpdateProcessor`](../../src/Application/IncomingUpdateProcessor.php), извлечение текста и данных пересылки — [`IncomingMessage`](../../src/Telegram/Dto/IncomingMessage.php).

История произвольных каналов автоматически не читается; список каналов настраивать не нужно. Сообщения из групп и каналов напрямую этот сценарий не принимает. При пересылке часть сведений об источнике и исходная тема могут быть недоступны. Передавайте только контент, который вправе обрабатывать; для облачного анализа учитывайте передачу выбранному сервису.

Оценка придёт в тот же личный чат. Значение вердиктов и пометок источника объясняет [справочник результатов](../reference/analysis-result.md). Если бот молчит или сообщает об ошибке, откройте [устранение неполадок](troubleshooting.md).
